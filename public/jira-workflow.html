① One-Time Setup
Admin CTT Config
Configure Jira credentials per product
Set Base URL, email, API token per product (EasyOrder, Connect Client…). Token is AES-256 encrypted at rest — never exposed.
⚙ One-time
Admin CTT Config
Set project key + pull statuses
e.g. project key EO, pull status "In UAT". CTT only pulls Stories and Tasks — Bugs, Defects, and sub-tasks are excluded automatically.
⚙ One-time
Admin CTT Config
Set Jira transition names
jiraInUatTransition → default "In UAT"
jiraReadyToDeployTransition → default "Ready to Deploy"
Must match exact transition names in your Jira project workflow.
⚙ One-time
Jira Admin (once)
Confirm these transition names exist in the Jira project workflow. Generate an API token at id.atlassian.net → Security → API tokens and give to CTT admin.
② Routine Workflow — per Jira ticket
Admin JIRA Queue
Open JIRA Queue
CTT fetches all Jira tickets in the configured status for your assigned products. Each ticket is a card in the galaxy view. Click the ticket key pill to open it in Jira.
↻ Per sprint
Admin JIRA Queue
Create CTT task from unlinked card
Click Create Task on any unlinked card. Modal pre-fills ticket key, title, product. Admin adds countries, test steps, assignee. Jira ticket shows Linked ✓ badge.
↻ Per ticket
CTT Automatic
Jira ticket auto-transitions → In UAT
On task save, CTT calls the Jira Transitions API. Silently skipped if the transition doesn't exist — the task save always succeeds regardless.
⚡ Automatic
Jira · Board
Ticket now appears in the In UAT column. QA team picks it up and runs testing across all applicable markets (MY, SG, TH, ID…).
Admin JIRA Queue
Card shows linked CTT tasks
"Create Task" CTA disappears. Card lists all linked tasks with status badge + country pill. One Jira ticket can map to multiple countries — each appears as a separate row.
↻ Ongoing
③ SIT Sign-off Detection
QA Team In Jira
Comments SIT completion on the Jira ticket
Posts: "SIT for this user story is completed." and attaches the test script. CTT uses fuzzy matching — typos and grammar variations are tolerated.
↻ Per ticket
CTT Automatic
Detects SIT comment on next JIRA Queue load
Fetches up to 100 comments per ticket (max 5 concurrent to avoid Jira rate limits), sorted newest-first. Handles both ADF and plain-text comment bodies.
⚡ Automatic
CTT Automatic
Emerald SIT panel + nav badge appear
Card shows the comment excerpt — click it to jump directly to that Jira comment (focusedCommentId). Nav badge shows count of unacknowledged SIT items.
⚡ Automatic
Admin JIRA Queue
Acknowledges SIT
Clicks Acknowledge SIT ✓. All CTT tasks linked to this Jira ticket get sitSignedOffAt stamped. Card shows "✓ Acknowledged". Nav badge decrements.
↻ Per ticket
Stakeholder Task Detail
Reviews task + signs off in CTT
Reviews test steps, actual results, and the SIT sign-off date in Task Detail. Signs off the task. Full audit trail: Jira link, SIT date + comment, signature, per-country coverage.
↻ Per task
CTT Automatic
Jira ticket auto-transitions → Ready to Deploy
On sign-off, CTT calls the Jira Transitions API. Ticket moves to jiraReadyToDeployTransition. Dev team sees it's cleared for release.
⚡ Automatic
Jira · Result
Ticket is now Ready to Deploy. Dev team picks up for release. Next ticket enters the routine from Step 4.
